┌─────────────────────────────────────────────────────────────────────────────────┐
│                            DATA FLOW EXAMPLES                                  │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  EXAMPLE 1: USER VISITS HOMEPAGE                                               │
│  ──────────────────────────────                                                │
│  1. Browser requests redwanmart.com → Cloudflare DNS routes to nearest edge    │
│  2. Edge serves Astro-generated HTML from Cloudflare Pages (~50ms globally)    │
│  3. HTML includes <img src="assets.redwanmart.com/products/...">              │
│  4. Images auto-resized & cached by Cloudflare Image Resizing                  │
│  5. Page loads in <1.5s with 100 Lighthouse score                              │
│                                                                                 │
│  EXAMPLE 2: FETCH PRODUCTS (API REQUEST)                                       │
│  ────────────────────────────────────────                                       │
│  1. Astro component calls fetch('/api/products')                                │
│  2. Request routed to Cloudflare Workers (compute edge)                         │
│  3. Worker queries D1 Database (cached in KV if <5min old)                     │
│  4. JSON response returned in ~100ms                                            │
│  5. Component renders product cards with images from CDN                        │
│                                                                                 │
│  EXAMPLE 3: ADMIN GENERATES PRODUCT IMAGES                                     │
│  ───────────────────────────────────────────                                    │
│  1. Admin enters product prompt in dashboard                                    │
│  2. POST /api/media/generate → Worker validates JWT                            │
│  3. Worker calls Higgsfield AI API (external)                                   │
│  4. Higgsfield generates image & returns URL in 30-60s                         │
│  5. Worker stores metadata in D1, uploads to R2                                 │
│  6. Webhook updates product record with CDN URL                                │
│  7. Website immediately shows new product image globally                        │
│                                                                                 │
│  EXAMPLE 4: DATABASE QUERY (OPTIMIZED PATH)                                    │
│  ────────────────────────────────────────────                                   │
│  1. First request: Query D1 directly (~200ms)                                   │
│  2. Response cached in KV for 5 minutes                                         │
│  3. Subsequent requests: Return from KV (~10ms)                                 │
│  4. Cache invalidated when products updated                                     │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
